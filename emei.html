⚠去之前，先记三件事

1. 云海看天吃饭：峨眉山最出片的是云海、日出、佛光，全部依赖天气。出发前盯紧预报，雨后初晴是拍云海佛光的黄金窗口；连日阴雨就别抱太大期望，改期比硬上好。
2. 防猴子：清音阁生态猴区和雷洞坪一带猴子多、会抢包抢食。别拎塑料袋、别当猴面掏包、别逗猴，零食藏进背包拉好拉链。被抢就松手给，别硬拉。
3. 旺季要提前：金顶住宿和景区索道节假日排队久，金顶住宿提前订；想拍日出务必住金顶（或提前一天住雷洞坪），否则赶不上。

📅行程总览（推荐 2 天 1 夜）

峨眉山不必全程徒步，「观光车到雷洞坪 → 徒步/索道上金顶」是摄影党最省力的精华走法；全程徒步约 50km+、2 天，适合老驴，这里一并给出。

天数路线徒步重点
Day 1成都→峨眉山→观光车到雷洞坪→金顶约 6km（或索道）日落 + 云海 + 星空
Day 2金顶日出/佛光→下山→返成都约 6km 下坡日出 + 佛光 + 云海

全程徒步线（进阶，约 50km+ / 2 天）

天数路线说明
Day 1报国寺→清音阁→洪椿坪→仙峰寺约 30km，最累段「九十九道拐」
Day 2仙峰寺→洗象池→雷洞坪→金顶约 20km，金顶看日落住一晚

多数人拍片走推荐线即可；想体验「峨眉天下秀」的千年古道再上全程徒步。

🚄交通（深圳 / 成都出发）

去程

  1. 深圳 → 成都：高铁约 8–9 小时（二等座约 800–900 元），或飞机约 2.5 小时（提前订更划算）。
  2. 成都 → 峨眉山站（高铁）：成都东 / 成都南出发，约 1–1.5 小时，约 65 元。出站有景区交通到报国寺（公交/打车，约 20 分钟）。
  3. 报国寺游客中心 → 雷洞坪（景区观光车）：全山段观光车约 2 小时，往返约 90 元。这是上金顶最省力的方式。

返程

  1. 金顶下山（索道 / 徒步）→ 雷洞坪坐观光车回报国寺 → 峨眉山站高铁回成都 → 成都返深圳。
时间锚点：Day 1 早上成都出发 → 约 11 点到峨眉山 → 观光车 2 小时到雷洞坪 → 徒步/索道上金顶 → 下午 4 点前到金顶，正好赶日落。

📷风光拍摄时间线

金顶日出随季节变化（夏约 6:00、冬约 7:00），出发前用天气 App 核对当日精确时间。云海/佛光最佳是雨后初晴。

Day 1（上山 + 日落 + 星空）

时间地点/动作拍什么
08:00成都出发高铁上补觉
11:00到峨眉山观光车到雷洞坪
13:00雷洞坪出发徒步/索道上金顶
16:00金顶西侧就位日落前黄金光，架三脚架
18:00–19:00日落云海 + 金佛 + 晚霞
19:00–19:40蓝调时刻十方普贤像 + 云海
21:00–23:00金顶平台银河 / 星轨（海拔 3079，光污染小）

Day 2（日出 + 佛光 + 返程）

时间地点/动作拍什么
05:00起床套上轻羽绒，金顶夜里接近 0℃
05:30金顶观景台占位早到抢机位
06:00–06:40日出云海日出
08:00–10:00金顶周边佛光（背对太阳、前方有云海雾时出现）

风光优先级：云海 > 日出 > 佛光 > 星空 > 猴群。体力有限时先保「日出」和「云海」两个黄金时段；佛光是可遇不可求的加分项。

📸摄影机位 + A7M4 专项

机位时间表

时间机位拍什么镜头
日落金顶西侧平台云海 + 金佛晚霞广角
夜里金顶平台/舍身崖方向银河、星轨广角大光圈 + 三脚架
日出金顶观景台云海日出广角 / 长焦
上午金顶背阳一侧佛光（人影入光环）广角 / 中焦
白天清音阁生态猴区猴子（长焦别靠太近）长焦 70–200mm

A7M4 参数（按镜头微调）

题材参数
云海日出光圈优先 f/8–11，ISO 100，三脚架，包围曝光 ±2EV
佛光f/8–11，ISO 100，别过曝，光环中心是你的影子，多试几个机位
银河/星轨M 档 f/2.8，ISO 3200–6400，快门 15–20s（500÷焦距）；星轨用内置间隔拍摄
猴子长焦 70–200mm，快门 ≥1/200s，保持距离别用广角凑近
古寺f/5.6–8，ISO 100，清晨侧光更出层次
A7M4 三大坑：① 上三脚架关防抖；② 关长曝光降噪（否则星轨没法连拍）；③ 拍佛光/云海光比大，用包围曝光后期合成。

镜头搭配

  • 广角（云海 / 日出 / 星空大场景）：16–35mm 或 24/35mm 大光圈定焦。
  • 长焦（猴子 / 日出特写 / 山脊压缩）：70–200mm f/2.8 或 f/4。

  • 防晒、雨衣、头灯
  • 充电宝、现金、身份证
  • 相机 + 广角/长焦 + 三脚架 + 备用电池

✅出发前 Checklist

  • 查峨眉山天气（重点看日出时间 + 云海概率，雨后初晴最佳）
  • 订好金顶住宿（节假日提前订）
  • 买好深圳↔成都、成都↔峨眉山高铁票
  • 下载景区地图 + 徒步轨迹（两步路/六只脚）
  • 买户外意外险
  • 装备：徒步鞋、登山杖、轻羽绒、头灯、雨衣、充电宝、三脚架
  • 相机：广角 + 长焦镜头、备用电池、存储卡
  • 备足现金 + 身份证（买票、寺庙住宿可能用现金）
一句话总结：成都高铁 1.5 小时到峨眉山 → 观光车到雷洞坪 → 徒步/索道上金顶（住一晚拍日落星空）→ 金顶看日出云海、碰碰佛光 → 索道下山返程。雨后初晴去，一次拍全云海、日出、佛光、星空。
预算（单人约 1300–2000 元，含深圳往返）：深圳↔成都往返（高铁/飞机按淡旺季）+ 成都↔峨眉山高铁 130 + 门票 160 + 观光车 90 + 金顶索道约 120 + 住宿 150–300 + 餐饮。

门票（峨眉山景区，以官方为准）：旺季 160 元 / 淡季 110 元。金顶索道上行约 65、下行约 55；万年索道上行约 65、下行约 45。

安全应急：① 猴子抢食——松手给，别硬拉别逗；② 高海拔 3079m，慢走防高反；③ 台阶湿滑，下山用登山杖；④ 遇雷雨别上金顶空旷处；⑤ 求救拨 110 或景区救援，报最近节点名（金顶/雷洞坪/清音阁等）。
